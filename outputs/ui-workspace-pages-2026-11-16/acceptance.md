# Единый стиль рабочих страниц

16 ноября2026. По просьбе пользователя «Заявки», «Клиенты» и «ИИ-квалификация» приведены к стилю упрощённых диалогов: спокойные поверхности, основные действия на виду, редкие настройки раскрываются по необходимости. Общие стили scoped через workflow-page, другие экраны не перекрашиваются.

Заявки: очередь/выбранная карточка, статус поиска и пауза видны сразу. Выбор чатов и инструкция/порог/редкие команды скрыты в раскрытия; параметры редактируются отдельно, основное действие явно предупреждает «Подтвердить и написать клиенту». Отклонение раскрывает причину. Результаты отправок и pending-operation guards не изменены; реальные approve/reject/pause/start при визуальной проверке не выполнялись.

Клиенты: база вместо постоянно открытого импорта. Импорт и первое обращение раскрываются отдельно; видимые колонки — клиент, телефон, ограничения, ссылка в диалог. Комментарий/этап показываются по раскрытию, запрет сообщений остаётся видимым. На390px таблица становится карточками. Пагинация не показывается, когда страница единственная; большие списки сохраняют управление страницами.

Квалификация: основные вопросы и условия отбора, единая кнопка сохранения с состоянием изменений. Шаблоны/знания/тон/лимит/провайдер и чат уведомлений раскрываются отдельно. Технические версии не вынесены в основной интерфейс, но expectedVersion/revision продолжают передаваться API. Настройки не пишутся автоматически при открытии или раскрытии. Рабочая конфигурация пользователя не менялась.

Проверки: npm run typecheck PASS; vite production build PASS. Desktop и390x844 осмотрены на всех трёх страницах. Подтверждены переход из клиента в его диалог, доступность файлового импорта (без загрузки файлов), чтение выбранной заявки и скрытие технического редактора. На одноразовом synthetic API вопрос изменён, раскрытие шаблонов сохранило введённое, Save показал успех; reload сохранил вопрос и условие10. Synthetic-стенд затем остановлен с очисткой собственных схем/Redis/uploads. Фото settings-synthetic-saved.jpg — вымышленный round-trip; остальные скриншоты с разрешённым реальным тестовым контактом остаются локальными и не включаются в Git.

Backend-логика не менялась, существующие376 backend PASS не заменяют отдельные незавершённые пункты общей release-приёмки.
