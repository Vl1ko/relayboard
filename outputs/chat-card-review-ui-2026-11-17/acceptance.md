# UI-проверка трёх дополнений,17 ноября2026

Изолированный source-ui-fixture: fake аккаунты/контакты, отдельная схема и Redis, API без владельцев мессенджеров и AI-worker. Нет настоящих сообщений, ключей или договоров.

- Настройка выбранного чата: видны inherit/extend/replace; отдельные критерии щебня, включение «щебень», исключения «продам»/«нужна машина» сохранены. `chat-criteria.png`.
- Карточка: заметка добавлена и сохранилась после reload; текстовый вымышленный договор загружен и появился как ссылка скачивания. `contact-card.png`.
- Предложение об отказе: manager_required/paused; явно написано, что прощание не отправлено; две кнопки решения. `review-pending.png`.
- Несогласие: «Не отклонять — взять в работу» переводит диалог в manager_working/manual, предложение снимается. `manager-takeover.png`.
- Для отдельного вымышленного клиента кнопка «Подтвердить отказ и отправить прощание» принята API, статус unqualified/paused. Отправки не имитировались этим стендом и закрытие по доставке не заявляется.

Подготовка числовой фикстуры выявила два ошибки именно фикстур: число было слито со словом («только5»), затем для одиночного канала использован канонический event key вместо переданного провайдеру messageId. Их исправили на раздельное число и фактический идентификатор из provider input; защитные проверки приложения не ослаблялись.
