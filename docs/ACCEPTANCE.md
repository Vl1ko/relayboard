# Чек-лист сдачи

- [ ] На сервере установлена версия 1.0.0, `/api/health` возвращает `ok`.
- [ ] В кабинете работают вход, выход и запрет доступа без сессии.
- [ ] В интерфейсе и API доступны только Telegram, MAX и WhatsApp.
- [ ] Подключены три личных аккаунта, проверено восстановление сессий.
- [ ] Импортированы согласованные 20 Telegram, 15 MAX и 40 WhatsApp групп.
- [ ] Во всех трёх платформах получены текст, ссылка, фото, видео, документ и несколько вложений.
- [ ] Проверены выбор одной/нескольких/всех групп и исключение групп.
- [ ] Проверены последовательность и заданный интервал.
- [ ] Проверены немедленный, разовый и минимум два повторных запуска по UTC+3.
- [ ] Проверены пауза, продолжение без дублей, остановка и отключение будущих повторов.
- [ ] Проверены временная, постоянная и неопределённая ошибки.
- [ ] Пройдены typecheck, unit, build, backend smoke и нагрузочные тесты.
- [ ] Переданы исходники, схема БД, инструкции запуска, backup/restore и перечень зависимостей.

Пункты с реальными аккаунтами подписываются после предоставления Заказчиком доступов и тестовых групп.
