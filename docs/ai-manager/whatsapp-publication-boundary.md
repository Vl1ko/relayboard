# Подготовленная публикация WhatsApp

15 ноября 2026. Автономный transport-инкремент F03:360 PASS/0 FAIL/0 SKIP, typecheck/build PASS; MAX/WhatsApp/AI owners проходят проверку двух процессов/SIGKILL без повторной отправки. Временный настоящий Chrome/CDP с синтетическими WAWeb-модулями подтвердил подготовку текста и группового медиа, exact reserved ID/server ack, отказ при смене self, unknown при ack0. Реального WhatsApp login, сетевых сообщений и модели не было.

`/send` принимает durable delivery ID; текст, адрес и вложения берутся из БД. RPC не может подменить их. Все файлы проходят проверку размера и подготовку/загрузку до первого сообщения. Для группы выбирается фактический self/participant; каналы/newsletter/status этой реализацией не поддерживаются. Закреплённый профиль и generation проверяются перед стартом.

Перед каждым сообщением публикация/доставка блокируются; повторно проверяются pause/stop/completed, истечение файлов, неизменность текста, аккаунт и destination. Подготовленный start синхронно пишет CDP-команду. Подтверждение требует именно зарезервированный ID и server ack; локальный ID не является доставкой. Если остановка произошла после одного файла, операция становится unknown целиком; пакет автоматически не повторяется. Ошибка до любого старта удаляет только свою незапущенную receipt и позволяет свежую проверку.

Тесты:20 конкурентных RPC дают один старт; pause/изменённый адрес во время подготовки дают0 стартов; все файлы подготовлены до первого старта; частично начатый пакет не пересылается.
