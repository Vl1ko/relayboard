## Если что-то остановилось

- Диск: приостановить новые публикации/источники, снять df/объёмы PG/Redis/logs/uploads, проверить storage preview и подтверждённые сроки. Не удалять WAL, pgsql_tmp работающей БД, profiles или unknown media. Не выполнять VACUUM FULL на заполненном диске.
- Авторизация: выключить проблемный аккаунт, переподключить через UI, проверить self identity и разрешённую личку. Pending ждёт готовности; unknown не повторять после смены токена.
- Модель: проверить флаги/credential/scope/квоту и очередь; provider failure не считается успешной квалификацией. Коммерческие факты без настроенных знаний — менеджеру.
- Worker: проверить owner/health/heartbeat, перезапустить единственного владельца; после сбоя сверить durable outcomes. Не запускать параллельную ручную сессию на тех же профилях.
- Резервная копия: проверять manifest/hash и доступность Mac/ключа, использовать recovery-runbook. Ни Compose health, ни зелёный API сами по себе не доказывают живую авторизацию всех аккаунтов.
