# Рабочее место менеджера: приоритет и ручной ответ

Миграция20 добавляет приоритет контакта: высокий, обычный, низкий. Карточка сохраняет его с проверкой ревизии; фильтр и сортировка используют сохранённое значение. Приоритет не меняет статус, критерии, режим автоматики или очередность уже начатых отправок.20 одновременных сохранений одной ревизии дают одно изменение и19 конфликтов.

Ручной ответ из карточки использует выбранный личный диалог/аккаунт, UUID операции и общую постоянную outbox. В live-режиме проверяются активная заявка, проверенный маршрут, включённый авторизованный аккаунт и разрешённая тестовая область читателя/получателя. Проверки выполняются внутри транзакции перед новым намерением; повтор уже принятой операции возвращает прежнее намерение. Синтетический ввод входящих событий остаётся выключенным в live-режиме. Исторический закрытый канал контакта не запрещает ручной ответ в текущем открытом канале.

Ручной ответ переводит автоматизацию контакта во «Вручную» и отменяет автоматические ожидания. Manager hold сохраняется; ответ менеджера не разрешает ИИ продолжать квалифицированную заявку. Запись в очередь не называется доставкой. Подтверждение/unknown видны в списке операций. Экран отличает синтетическую имитацию от live-очереди. Обновление той же карточки сохраняет номер записанной операции; отправка во время перезагрузки данных запрещена.

Проверки:335 PASS /0 FAIL /0 SKIP, typecheck, production build, четыре compiled process/Chrome smokes. В синтетическом браузере сохранён высокий приоритет и два разных ручных намерения; реальные отправки не происходили. Повторная проверка исправила сброс подтверждения после обновления карточки.
