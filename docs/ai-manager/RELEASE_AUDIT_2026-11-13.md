## Существенные ограничения реализации

1. `src/ai-worker/index.ts` допускает только `AI_SEND_MODE=synthetic` и использует syntheticTransport. Это не production AI worker.
2. `src/core/max-qualification-session.ts` — один локальный account/dialog в API, poll последних50 сообщений, in-memory session. `src/api/local-max-test-router.ts` включён только на localhost и БД relayboard_local_max; источники и привязки имеют in-memory TTL. Этот модуль нельзя объявить релизным мониторингом.
3. `src/whatsapp-bridge/index.ts` поддерживает старые публикационные функции, но не подключает AI inbound/events к новому оркестратору.
4. `src/core/begin-qualification.ts` правильно запрещает closed/refused/manager_hold, но не реализует цикл новой заявки после закрытия. Conversation unique(account,external_id) и один engine_state сами по себе не выражают несколько независимых заявок.
5. `src/core/max-manager-notification.ts` отправляет только reason=qualified. После решения пользователя должны отправляться все4 причины из ТЗ, а unqualified не должен становиться qualified.
6. Политика30 дней для переписок ещё не реализована: нужно очищать не только inbox, но и копии текста/цитат в decision JSON, источниках, резюме, логах и backup policy. История ожидания менеджера не является завершённой.
7. Основной `docker-compose.yml` не запускает новый live AI worker; overlay ai пока synthetic. Health API не доказывает здоровье коннекторов/очередей.
8. Старые requirements.md/open-decisions.md и верх progress.md содержат исторические статусы. Их нельзя использовать как текущую оценку; при исполнении плана нужен единый обновлённый реестр.

## Условия GigaChat

По официальной документации Freemium — личное некоммерческое использование; для коммерческой эксплуатации нужен соответствующий платный доступ. Физлицу доступен один поток, это не20 одновременных model requests. Пользователь согласовал включить коммерческое подключение в план, без покупки сейчас.

Источники, проверенные13.11.2026:
- https://developers.sber.ru/docs/ru/gigachat/tariffs/commercial
- https://developers.sber.ru/docs/ru/gigachat/limitations

Вывод: есть работающий локальный сценарий MAX и проверенное ядро, но готовность12/12 ТЗ и промышленная эксплуатация пока не подтверждены. Следующие действия — только после утверждения плана.
