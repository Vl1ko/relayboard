# Программа тестирования

## Автоматические проверки

```bash
npm ci
npm run typecheck
npm test
npm run build
node work/backend-smoke.mjs
```

Smoke-тест не отправляет сообщения: создаёт отложенное тестовое задание, проверяет вход, файл и жизненный цикл, затем удаляет данные.

## Нагрузочные испытания

Control plane: `LOAD_CONCURRENCY=50 LOAD_DURATION_MS=600000 node work/control-plane-load.mjs`. Критерии: ошибок менее 1%, p95 менее 300 мс, p99 менее 800 мс на согласованном сервере.

Очередь: отдельный `QUEUE_NAME`, `MESSENGER_SEND_MODE=fake`, `QUEUE_DELAY_SCALE=0`; 20 циклов по 75 доставок. Критерии: 1500 доставок, 0 потерь, 0 дублей, 0 ошибок. Реальные мессенджеры для нагрузки не используются.

## Приёмочные проверки на реальных аккаунтах

В двух разрешённых тестовых группах каждой платформы проверить: текст, ссылку, фото, видео, документ, смешанный набор файлов, немедленный запуск, отложенный запуск после закрытия браузера, два повтора расписания, паузу/продолжение и остановку. Зафиксировать версию, время, скриншоты и ID сообщений.
