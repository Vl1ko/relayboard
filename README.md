# Relayboard 1.0.0

Сервис рассылки сообщений от личных аккаунтов в существующие беседы Telegram, MAX и WhatsApp. Сообщение может содержать текст, ссылки и до 10 фото, видео или документов. Доставка выполняется последовательно с заданным интервалом.

## Возможности

- личный кабинет с логином, паролем, серверной сессией и выходом;
- по одному личному аккаунту Telegram, MAX и WhatsApp;
- импорт доступных групп и ручное добавление существующей беседы;
- выбор одной, нескольких или всех бесед;
- несколько файлов до 100 МБ каждый в одной публикации;
- немедленный, отложенный и повторяющийся запуск по Москве (UTC+3);
- пауза, продолжение без повторной отправки, остановка и отключение повторов;
- настраиваемые интервал, число попыток и задержка повтора;
- отдельный статус неопределённого исхода без опасного автоматического повтора;
- журнал доставки с понятной причиной ошибки и ручным повтором.

## Быстрый запуск

1. Скопируйте `.env.example` в `.env`.
2. Задайте уникальные длинные значения секретов. `ADMIN_PASSWORD` — пароль кабинета, `ADMIN_USERNAME` — логин.
3. При наличии укажите Telegram `api_id` и `api_hash`. Если оставить их пустыми, поля появятся перед QR-входом.
4. Запустите:

```bash
docker compose up -d --build
```

Панель доступна на `http://localhost:3001`. Проверка состояния:

```bash
curl http://localhost:3001/api/health
docker compose ps
```

Если `ADMIN_PASSWORD` не задан при обновлении старой установки, временно используется прежний `ADMIN_API_KEY`. После первого входа задайте отдельный пароль в `.env` и перезапустите API.

## Подключение аккаунтов

### Telegram

Сохраните подключение, откройте блок Telegram и нажмите «Войти через QR». На телефоне выберите Telegram → Настройки → Устройства → Подключить устройство. При включённой 2FA введите пароль в панели; он не сохраняется. После статуса подключения импортируйте группы.

### MAX

Войдите рабочим аккаунтом на [MAX Web](https://web.max.ru), получите токен активной web-сессии и вставьте его в форму. После проверки нажмите «Загрузить группы». Интеграция личного аккаунта использует неофициальный web-протокол: выход из MAX Web, изменение протокола или ограничения платформы могут отозвать сессию.

### WhatsApp

Сохраните подключение, нажмите «Проверить QR-сессию» и отсканируйте код в WhatsApp → Связанные устройства. После статуса подключения импортируйте группы. Используется WhatsApp Web, а не Cloud API.

## Эксплуатация

- сервер должен работать постоянно; закрытие браузера не влияет на очередь;
- используйте HTTPS reverse proxy и установите `SESSION_COOKIE_SECURE=true`;
- не публикуйте PostgreSQL, Redis и bridge-порты наружу;
- каталог вложений, база и сессии находятся в Docker volumes;
- перед реальной рассылкой проверьте каждый тип контента в разрешённых тестовых группах;
- соблюдайте правила платформ и используйте отдельные рабочие аккаунты.

Документы сдачи находятся в каталоге [`docs`](./docs): развёртывание, резервное копирование, тестирование, приёмка и известные риски.
